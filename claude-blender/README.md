# Claude Blender

Animation made by Claude driving Blender: scenes, characters, cameras and lights built from Python (`bpy`), rendered headless frame by frame, then cut, scored and mixed like every other production here.

Each film gets its own folder: `claude-blender/<slug>/` with a `README.md`, `design/DECISIONS.md` and `design/SHOTS.md`, `scenes/` (the Python that builds each scene and shot), `assets/` (models and textures that may be committed, with their licences), `tools/`, `audio/` and an ignored `out/` for renders and `.blend` caches.

How to make one: `.claude/skills/cines-engine/references/claude-blender.md`.
