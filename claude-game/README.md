# Claude Game

Videos for games made with Claude: trailers, openings and title sequences, prologues, credits, sky panoramas and films shot inside the game's own engine.

| Production | What it is |
| --- | --- |
| [`crownfall-intro/`](crownfall-intro/README.md) | Crownfall's opening and title sequence, and how the game's files are cut from it. |
| [`crownfall-prologue/`](crownfall-prologue/LOOK.md) | The prologue, with a painterly finish (parked as work in progress). |
| [`crownfall-arena-skies/`](crownfall-arena-skies/README.md) | The Eclipse and Violet Night arena skies, painted in code as panoramas. |
| [`crownfall-credits/`](crownfall-credits/README.md) | Credits cards gathered from every Crownfall branch. |
| [`crownfall-ealdholt-opening/`](crownfall-ealdholt-opening/README.md) | House Ealdholt's My Legacy opening, shot inside the game's own three.js village, with a Stable Audio soundtrack. |

The studio skill (`.claude/skills/cines-engine/references/claude-game.md`) covers the capture methods (in-engine film hooks, painted in code, gameplay capture), sound and delivery to the game.
