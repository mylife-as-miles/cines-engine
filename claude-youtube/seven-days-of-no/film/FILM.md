# Seven Days of No: the engine

The video is code. `FILM.renderAt(t)` draws any instant of the 225.5 s timeline (1920×1080, 24 fps) on the **narration clock**: the player scrubs it with the voice, the exporter steps it frame by frame. It is deterministic: never `Math.random` or `Date` (use `FILM.rng(seed)`, `FILM.wob`, `FILM.noise1`). Ported from *Long Distance*'s engine, without the paper finish (flat cartoon).

| File | What |
| --- | --- |
| `film/engine.js` | Clock, word anchors, motion helpers, timeline, camera and push, transitions, sound cues, chapters |
| `film/art.js` | `ART`: the adapter to the art kits. `c.set`, `c.fig`, `c.prop` use `SETS` (`kit/sets.js`) and `POV.figure` (`kit/pov.js`) when loaded, labelled placeholders when not |
| `film/gfx.js` | `GFX`: the explainer graphics the kits lack (bubbles, cross, cloud, sprout, memory frame, portraits, comment bubble, word cards, the friend's flat, Mum's kitchen, bunting) |
| `film/stage.js` | `STAGE`: shared staging (day card, stamp, pill/button, phone screen, split-screen call, bulb, thought, notifications, the hero on the sofa, the plain bust). Uses the Sets kit's overlays (`SETS.dayCard`, `SETS.pill`, `SETS.stamp`, `SETS.phoneScreen`, `SETS.call`) when present |
| `film/sound.js` | Development stand-ins for the named cues (player only) |
| `film/words.js`, `film/vo_env.js` | Generated by `tools/film.js` from `audio/vo/words.json` and `out/vo/narration.wav`. Do not edit |
| `film/seq/QNN_*.js` | Q01 to Q11 and Q12 (end screen), in story order (`film/load.js`) |
| `film/index.html` | The player (the narration drives the clock; `?audio=../out/mix.wav` plays a mix instead). `film/headless.html` is for the tools |

## A sequence

```js
(function () {
  const { W, Wend } = FILM.from(FILM.W('Monday'));        // anchors counted from this sequence's first word
  const T = { card: W('Monday'), boss: W('your boss'), ask: FILM.span('can you stay', 'tonight'), no: FILM.span('no', null, W('today')) };
  FILM.seq({
    id: 'Q02', title: 'Monday: the boss', chapter: 'Monday: the boss', from: T.card,   // lasts until the next sequence's `from`
    sound(S) { S.bed('music', T.card, FILM.W('Tuesday'), { mood: '...' }); S.cue('footsteps', W('walks'), { n: 4 }); },
    shots: [   // a shot lasts until the next shot on the timeline
      { at: T.card, name: 'office: the day card', in: { type: 'wipe', dir: 'right' }, push: 1.04,
        draw(c) { c.set('office', { clock: '5:30' }); c.fig('hero', { x: 560, y: 962, pose: 'stand' }); STAGE.dayCard(c, T.card, T.boss, 'MONDAY', '5:30 PM'); } },
      { at: T.boss, name: 'office: the boss asks',
        draw(c) { c.set('office', {}); c.fig('boss', { x: 1300, y: 962, face: -1, pose: 'hold_clipboard', talk: T.ask }); } },
    ],
  });
})();
```

- **Every time is a word anchor** on the narration clock (global seconds); never a typed number where a word exists.
  - `FILM.W('Monday')` is the first match's start; `W('no', 3)` the third; `W('no', { after: t })` the first after `t`.
  - Phrases match consecutive words (`W('not fine')`, `W('five thirty')`). Punctuation and case are ignored.
  - `Wend(...)` is the spoken end of the last word: Whisper gives a sentence's last word the pause after it, so the end is read from the loudness envelope.
  - `FILM.span(first, last, after)` is `[start, end]` of a spoken line, for `talk`.
  - Use `FILM.from(t)` per sequence. Watch for day names inside sentences ("move on Saturday?"): Q07 anchors on `W('saturday your boss')`.
  - A missing anchor warns (in `strip.js` output) and falls back to the search start. So does a sequence out of story order.
- `c` per frame:
  - `c.t` is global seconds, `c.lt` sequence-local, `c.st` shot-local; also `c.shotDur` and `c.frame`.
  - `c.camera({x, y, zoom, dx, dy, rot})` frames world point (x, y) at the centre, clamped to the set's edges; the set gets it as `opts.cam` and draws at that resolution.
  - `c.reset()` gives world space (with the shot's push and shake); `c.screen()` gives raw screen space.
  - `c.cache(key, fn, w, h)` keeps a static layer. `c.flash(alpha)` draws a white flash over the frame. `c.shake({dx, dy})` and `c.impact(t0, dur, amp)` shake the frame: call them **before** drawing.
- Shot transitions (`in`): `cut` (default), `wipe` (a coloured band; `dir`, `color`), `slide`, `fade`, `dip`, `pop` (scale-in, for graphics), `iris` (`x`, `y`); each takes `dur`.
- Camera push: `push: 1.05`, or `{from, to, x, y, ease}`, over the shot. Never below 1: that shows the frame edge, and the engine warns.

## Motion helpers (all from `t`, all deterministic)

`FILM.walk(t, t0, t1, xa, xb, {s, stride})` returns `{x, walk, moving, face}`; pass `walk` and `face` to `c.fig` with `pose: 'walk'` (or `'run'`).

- `FILM.talk(t, span|spans)`: mouth 0..1 from the narration's loudness, gated to the words. `c.fig(who, { talk: span })` does this for you.
- `FILM.blink(t, seed)`: seeded blinks (automatic per character). `FILM.blinkAt(t, [times])` scripts them (`c.fig(..., { blinks: [...] })`).
- `FILM.pop(t, t0, d)`: a squash pop-in `{s, sx, sy, a, on}`. Also `FILM.popOut(t, t1)` and `FILM.popInOut(t, t0, t1)`. `GFX.at(g, x, y, state, fn)` applies any of them.
- `FILM.stamp(t, t0)` (`STAGE.stamp(c, x, y, t0, 'NO')`): a stamp landing with a shake.
- `FILM.flash(t, t0, d)`: a camera flash. `FILM.quake(t, t0, d, amp)`: a screen shake.
- Others: `FILM.tremble(t, amp)`, `FILM.nod(t, [times])`, `FILM.punch(t, [times], amt)` (quick push-ins), `FILM.slide(t, t0, from)`, `FILM.breath`.
- Easing and keys: `FILM.seg`, `FILM.key`, `FILM.ease.*`, `FILM.twos`.

## Art (the kits' contract, as the adapter calls them)

**Sets.** `c.set(name, opts)` calls `SETS[name](g, opts)`, and `c.setFront(name, opts)` calls `SETS[name + 'Front']`.
- The sets are `office` (`view: 'desk'|'door'`, `night`, `clock: '9:20'`), `living` (`tod: 'evening'|'morning'|'dusk'`, `todTo`/`todK`, `bird`, `table`), `street` and `plain`.
- `c.anchor(set, name)` returns `{x, y, s}` in world px, from the set's `anchorsSet`.
- `ART.tintFor(c, 'living')` is the set's figure tint.

**Characters.** `c.fig(who, opts)` calls `POV.figure(g, who, ...)`.
- Its options are `x, y` (the feet), `s` (1 = 800 px tall), `face` (±1), `pose`, `expr`, `walk`/`phase`, `talk`, `blinks`, `mouth`, `nod`, `look`, `hold`, `mode`, `seat`/`view` (for `sit`), `tint`, `faceOver` (POV's face override), `override`, `alpha`, `tremble`, `dx`, `dy`.
- It returns the options with `A`, the figure's anchors in world px (head, headR, hands); `ART.head` and `ART.hand` read them.
- Poses: POV's, plus the engine's `run`, `handup`, `stomach`, `peace`, `type`, `finger_up`, `push_away`, `hold_card`, `sit_front`, `sit_phone`, `sit_laptop`, `sit_stomach` and `sit_handup`.
- `STAGE.sitAt(c, set, anchor)` seats a figure on a seat anchor.

**Props.** `c.prop(name, opts)` uses `POV.PROPS[name]` (for example `phoneFlat`, `buzz`, `flash`, `plateIcon`) or falls back to `GFX`.

**Placeholders.** Run a tool with `--placeholders` to leave the kits out; every set and figure then draws as its labelled placeholder.

## Sound

- `S.cue(name, t, params)` is a one-shot; `S.bed(name, t0, t1, params)` is continuous. `S.duck(t0, t1, level)` lowers the music; `S.silence(t0, t1)` drops music and effects (the voice stays).
- Name every sound you mean, anchored to its word. `node tools/cuesheet.js` writes them to `out/cuesheet.json` for the mix, each cue with its nearest spoken word.

## Tools

```
node tools/film.js sync [--force]     # rebuild film/words.js and film/vo_env.js (the tools also do it when the sources are newer)
node tools/strip.js Q02 1 [out.jpg] [--placeholders]   # contact sheet every 1 s (or ALL, or a range "120-140"), ms per frame, warnings
node tools/frame.js Q02 3.5 out.png   # one frame (sequence-local); ALL 27.8 for global; ALL w:blinks for a word anchor
node tools/export.js out/seven_days_picture.mp4 --workers 3 --crf 20 --maxrate 6M --no-audio --no-join
node tools/cuesheet.js                # out/cuesheet.json
```

`export.js` takes `--from`, `--to`, `--only Q03`, `--scale 0.5` and `--audio <wav>` (default `out/vo/narration.wav`, padded to the end screen). `--no-join` keeps `out/export_tmp/seg_*.mp4` and `segs.txt`, a concat list. The full picture renders in about 2.5 min with 3 workers (about 31 MB at CRF 20).
