# Claude YouTube

Videos made for YouTube, the Claude Film way but shaped for the platform: long-form uploads and cuts of films, Shorts and vertical reframes, chapters, captions (SRT and burned in), thumbnails tested against each other, and the post copy that goes with them.

Each video gets its own folder: `claude-youtube/<slug>/` with a `README.md`, `design/DECISIONS.md`, `tools/`, `audio/` and an ignored `out/`. A YouTube cut of an existing film stays with that film (as *Autopilot*'s does, in `claude-film/autopilot/cuts/`); this studio is for videos made for YouTube first.

How to make one: `.claude/skills/cines-engine/references/claude-youtube.md`.
